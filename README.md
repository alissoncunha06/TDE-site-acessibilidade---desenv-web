# Acesso para Todos

Site sobre acessibilidade no dia a dia, feito em HTML, CSS e JavaScript. Fala do que é acessibilidade, de quem ela ajuda e de como ela aparece em casa, na rua, na escola, no trabalho e na internet. Também tem as principais leis e onde pedir ajuda.

Site no ar: https://alissoncunha06.github.io/TDE-site-acessibilidade---desenv-web/index.html

## Páginas

- index.html: o que é acessibilidade, barreiras e desenho universal
- casa.html: adaptações dentro de casa
- rua.html: calçada, piso tátil, transporte e vagas
- escola-trabalho.html: educação inclusiva, Lei de Cotas e adaptações no trabalho
- internet.html: recursos do celular e do computador, leitor de tela e WCAG
- direitos.html: leis e canais de denúncia
- sobre.html: recursos do site, atalhos de teclado, fontes e créditos

## O que o site tem de acessibilidade

- Botões A+ e A- para o tamanho da letra
- Alto contraste
- VLibras (tradução para Libras)
- Links para pular para o conteúdo, o menu e o rodapé
- Índice em cada página e "Voltar ao sumário" no fim das seções
- Texto alternativo nas imagens
- Dá para navegar só com o teclado
- Layout que se ajusta ao celular

## Pastas

- css/ com o style.css
- js/ com o acessibilidade.js
- img/ com as imagens

Para ver o site, é só abrir o index.html no navegador.
